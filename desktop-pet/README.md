# 宠物桌面生成器 MVP

这是一个本地优先的 Windows 桌面宠物原型：选择几张宠物照片，程序会先去除背景并预览透明主体，确认后生成动作资源包，并可在 Windows 上调用 PyInstaller 打包成单文件 `.exe`。

现在同时包含 Docker 服务端版本：浏览器上传照片后，服务端可调用 AI 图像服务生成动作帧，再由 Windows Worker 完成最终 exe 打包。服务端说明见 [server/README.md](server/README.md)。

Windows Worker 和 Windows + AI 交接步骤见 [WINDOWS_WORKER_HANDOFF.md](WINDOWS_WORKER_HANDOFF.md)。

## 已实现

- 无需服务器即可处理照片，原始照片不会上传。
- 透明、无边框、可拖动的桌面窗口。
- 常态保持待机，超时自动睡觉；走动和点击反应只在互动时触发。
- 右键菜单：开始走动、立即睡觉、恢复活动、退出。
- 支持一张照片起步，也支持多张照片作为动作/备用帧。
- 服务端先通过 AI 提示词生成透明主体预览，确认后再生成透明动作帧，并提供动作资源预览。
- 统一的身份参考图、透明化、落地基线和主体比例处理，减少不同动作帧漂移。
- 一整个动作序列共用一个渲染比例，并按“alpha 重叠配准”对齐到该序列的参考帧（面积中位数的那一帧），而不是按每帧各自的包围盒缩放和贴底；抬腿、伸爪、甩尾都不会再让身体忽大忽小或上下弹跳。配准在工程分辨率上做粗搜 + 细搜，并用抛物线拟合取到亚像素；整段序列的越界只做一次整体平移或整体缩放，绝不单独动某一帧。
- 姿态计划是动作周期的均匀采样：相邻两帧（包括循环首尾）永远不会收到同一个姿态描述，循环接缝的相位差与其它步进一致。
- 服务端可按动作生成默认 16/12 张有序走动/睡觉 PNG，并导出 `animation.json` 与可选 `skeleton.json`。
- 长动作默认改为“一次请求生成整张拼图”再确定性切帧：`ATLAS_MODE=auto` 时，4 帧以上的动作先请求一张 5x2 之类的精灵表，服务端用固定网格切分并检查每格是否为空、是否被切断、主体大小是否一致；任何一格不合格就自动退回逐帧生成，不会把坏图写进资源包。
- 每个生成任务都可以选择待机、走动、睡觉和点击反应中的一个或多个动作；未选择的动作使用照片/程序化动画兜底，不调用 AI。
- 动画可设置每帧保持次数；动作资源预览支持按动作播放、逐帧前后查看、删除突变帧和插入新帧，修改后会自动重排并更新下载包。删除或插入帧后会沿用同一套渲染契约（相同比例、相同参考帧、冻结的基准落点），不会因为编辑而让整个动作重新缩放。
- 每帧都会做质量自检：主体大小突跳、配准离群、与整段动作身份不一致（直方图 + 平均颜色）的帧会被标记，资源预览里可直接看到标记并按提示重新生成；少于 3 帧的动作不做判定。
- 即使已经生成并下载 Windows exe，也可以从任务历史重新打开同一任务继续编辑动作帧，编辑后再次请求 Worker 生成新版 exe。
- 运行中的去背景、动作生成、资源编辑和 Windows Worker 任务都支持“停止并保存断点”，之后可继续恢复。
- Windows 上通过 PyInstaller 生成包含资源的单文件 exe。
- 附带 `pet_atlas.py` 命令行工具，可以离线校验资源包、检查拼图网格、切图、逐行镜像，或按统一比例重新对齐一个手工改过的资源包（见下文）。

## Windows 上运行

建议使用 Python 3.11 或更新版本：

```powershell
cd desktop-pet
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python pet_creator.py
```

在生成器中选择照片后，点击“生成宠物”。默认会同时打包 exe；最终文件位于类似下面的目录：

```text
generated-pets/我的宠物/dist/我的宠物.exe
```

PyInstaller 不能可靠地把 Python 程序从 Linux 交叉编译成 Windows exe，所以最终 exe 应在 Windows 环境生成。也可以使用：

```powershell
.\scripts\build_creator.ps1
```

先把生成器本身打成 `dist/PetCreator.exe`，再让最终用户只运行这个生成器。

## 照片顺序

生成器最多接收 8 张照片，并按列表顺序分配：

1. 待机
2. 走动
3. 睡觉
4. 点击反应
5-8. 走动备用帧

只有一张照片也能工作，因为其他动作会在同一张照片上叠加轻微的缩放、上下浮动和旋转；资源包还会保存一个可复用的 2D 骨骼时间线。为了获得更自然的动画，建议照片主体完整、背景简单，并分别准备站立、侧身、趴下等姿态。

生成完成后，可以先预览资源包：

```powershell
python pet_runtime.py --config generated-pets/我的宠物/pet_config.json
```

## AI 动作帧与输出格式

服务端页面的“AI 配置（管理员）”支持：

- 要求 AI 从输入照片中分离宠物主体，并直接返回带真实 alpha 通道的透明 PNG；服务端不再使用本地分割模型。
- 选择图像模型：输入框带候选列表，“从网关拉取模型列表”会调用网关的 `/models` 拿出它真正支持的模型（读不到时退回内置常用名并说明原因），也可以直接手填自定义模型名。模型是账号级设置，保存在 `settings.json` 里。
- 每次生成还可以在上传区单独挑一个模型；留空就跟随账号设置。所选模型会写进任务的 `ai_config` 快照，因此这次任务的所有图像请求（去背景、逐帧/拼图生成、单帧重生成、插入帧）都用同一个模型，任务详情里也会显示“本次任务实际使用的图像模型”，之后再改账号设置也不会影响已创建的任务。
- 把第一张照片作为身份锚点，把其余照片作为动作参考，并在提示词中锁定毛色、脸部、比例、镜头、主体缩放和落地基线。
- 独立设置走动/睡觉帧数（默认 16/12，最多 24）、播放 FPS、每帧保持次数（1-4）和动作输出格式。
- 每个任务可在上传照片时选择要调用 AI 生成的动作；未选择的动作会保留照片/程序化动画兜底，因此最终桌面宠物仍然可以正常运行。

默认 `hybrid` 模式会同时包含：

- `assets/walk_*.png`、`assets/sleep_*.png` 等透明逐帧 PNG；
- `animation.json`：动作顺序、FPS、循环信息和姿态计划；
- `skeleton.json`：引擎无关的 2D 骨骼时间线。照片宠物使用 sprite-backed root rig，PNG 仍是视觉真值，便于后续接入 Spine/DragonBones/自研蒙皮渲染器。

如果只需要位图，可选择 `png`；如果只需要骨骼清单，可选择 `skeleton`。没有 AI 或 AI 失败时，资源包仍会使用照片和同一套骨骼/程序化动画兜底。

默认情况下动作帧按“一个姿态、一个请求、一个 PNG”逐帧生成（`ATLAS_MODE=off` 时始终如此）；后续帧会把上一帧作为时间连续性参考，单帧失败时保留序列位置，避免后续姿态整体错位。每张 AI 动作帧生成后还会再次经过 AI 去背景流程，避免兼容网关把棋盘格或绿幕直接画进 PNG。旧资源包需要重新生成。页面会展示生成的全部 PNG 帧，可勾选不和谐的帧后批量删除，也可在两个帧之间以前一帧为参考插入一帧；即使任务已经生成过 exe，仍可在任务历史中继续这些编辑，编辑完成后重新请求 Windows Worker；动画预览也可以运行 `pet_runtime.py` 或最终 exe。

编辑单个动作帧时，重新生成的帧会同时拿到“前一帧 + 后一帧”两张锚点图，并被要求落在两者之间；生成后仍然过一遍质量自检才算通过，未通过会自动带着具体问题（主体大小、配准、身份一致性）重试一次。

背景要求会写入 AI 提示词并启用透明背景：只保留宠物主体，优先输出带真实 alpha 通道的 RGBA PNG，不要白底、绿底、棋盘格、房间、地面或阴影。`gpt-image-2` 为兼容接口不会发送其不接受的 `background=transparent` 参数；如果网关仍返回不透明图片，动作帧会再次提交给 AI 去背景，服务端再用 Pillow 清理简单边缘，不使用 rembg。

常用环境变量：

```dotenv
POSE_CONSISTENCY=true
ANIMATION_MODE=hybrid
ATLAS_MODE=auto
AI_IMAGE_MODEL=gpt-image-1
ANIMATION_FPS=12
ANIMATION_FRAME_REPEAT=1
WALK_FRAME_COUNT=16
SLEEP_FRAME_COUNT=12
```

`AI_IMAGE_MODEL` 只是进程级默认值；它会被账号设置和单任务选择覆盖。

`ATLAS_MODE` 可选 `auto`（4 帧以上的动作先试拼图）、`on`（2 帧以上都试）和 `off`（始终逐帧生成）。拼图模式的请求次数约为逐帧的 1/N，而且同一张图里的主体大小、配色和光照天然一致；万一网关返回的拼图不合法，服务端会自动退回逐帧生成，因此打开它主要影响耗时和额度，不影响能否生成。

## 离线工具箱

`pet_atlas.py` 是不联网的 Pillow 工具，用来检查或修复已有的资源包：

```powershell
# 校验资源包：逐帧列出主体大小、配准、身份一致性问题（只读，不改动文件）
python pet_atlas.py validate --package generated-pets/我的宠物

# 检查一张拼图能不能安全切分
python pet_atlas.py grid-check --image sheet.png --frames 10

# 按固定网格切图（网格不合格时会中止，除非加 --force）
python pet_atlas.py split --image sheet.png --frames 10 --out .\frames --trim

# 逐行水平镜像，得到反方向的动作表
python pet_atlas.py flip-rows --image sheet.png --rows 2 --out sheet_mirrored.png

# 手工改过帧之后，按统一比例重新对齐整个资源包
python pet_atlas.py repack --package generated-pets/我的宠物
```

`validate` 会把帧标准化到临时目录里再测量，因此不会覆盖你的资源；`repack` 才会就地重写 `assets/` 下的帧，需要重新打包 zip 或重新生成 exe 后生效。

## 后续产品化方向

当前版本已经覆盖“能生成、能运行、能互动”的动画 MVP。后续可继续加入：

- 关键点/分割模型，把身体部位拆成真正可蒙皮的骨骼图层；
- 自定义行为编辑器、语音互动和系统托盘菜单。
- 生成任务队列、云端上传和下载链接（如果改成网站服务）。
- Windows 签名、自动更新和杀毒软件误报处理。
